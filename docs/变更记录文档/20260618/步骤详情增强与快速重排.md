# 步骤详情增强与快速重排（Qt/tk 统一）

**日期：** 2026-06-18
**分支：** feat/step-detail-reorder
**类型：** fix + feat

## 一、问题

1. **Qt 步骤详情「看不到信息」（bug）**：选中步骤后，Qt 属性面板（`QtActionChainPropsMixin._show_step_props`）只渲染了类型胶囊 / 序号 / 启用 / 备注 / 4 个按钮，**漏渲染 `step.describe()` 业务描述行** —— 这是与 tk 端相比唯一缺失的渲染项。
2. **参数不可见**：Qt/tk 两端都只靠 `describe()` 单行摘要，坐标 / 阈值 / 按键 / 等待时间等关键参数无法在面板直接看到，必须双击打开编辑对话框。
3. **重排手段单一**：`_move_step(±1)` 只能逐格上下移动，无法直接改序号、拖拽、多选批量或置顶置底。

## 二、根因

- Qt 漏渲染：纯实现遗漏（tk 端 `StepPropertyPanel.show_step` 有 describe，Qt 端 `_show_step_props` 没有）。
- 重排语义陷阱：`ChainModel.move_step(from, to)` 实际是 **swap（交换两节点内容）**，不是 insert（插入式移动）。对相邻 ±1 正确，但对「移动到指定序号 / 置顶 / 拖拽」会产生错误顺序（`[A,B,C,D]` 把 A 移到 2 位，swap(0,2) 得 `[C,B,A,D]`，期望 `[B,C,A,D]`）。

## 三、修复 / 新增

### 共用层（Qt/tk 共用同一 `ChainModel` + `ActionChainController`，改一次两端受益）

- **`ChainModel.reorder_steps(new_order)`**：insert 语义批量重排，按 `new_order`（原索引的新排列）重写所有 ACTION 节点的 `action/comment/enabled`，**不动 DAG 边**（与既有 `move_step` 的「换内容」模式一致，零拓扑风险）。非合法排列静默忽略。
- **`ChainModel.duplicate_step(index) -> int`**：深拷贝步骤，副本 insert 到 `index+1`，返回新索引；越界返回 -1（实现复用 `add_step` + `reorder_steps`）。
- **`ActionChainController`** 透传同名方法 + `move_to_index(index, target)`，均带 `_require_idle()` 保护（执行中拒绝，抛 `RuntimeError`）。
- 既有 `move_step`（swap）保留，仅用于 ↑↓ 相邻移动。

### 共用工具（`src/panel/components/`）

- **`step_param_view.py`**：纯函数 —— `build_move_order` / `build_batch_move_order`（按位置扫描，选中块整体平移）/ `build_top_order` / `build_bottom_order` / `format_field_value`（枚举→名、路径→basename、list→N 项、None→--、bool→✓/✗）/ `iter_all_fields`。
- **`step_key_fields.py`**：`KEY_FIELDS` 集中配置，为 16 种 ActionType 各定义 4-6 个关键字段 + i18n 中文标签。`key_fields_for(step)` 查表。

### 详情面板（Qt `action_chain_props_mixin.py` + tk `step_property_panel.py`，规格统一）

选中步骤后显示：
1. 类型胶囊 + `#序号/总数`
2. **describe 摘要**（修 Qt 漏渲染 bug）
3. **移动到序号**：输入框（1~N）+ 确定按钮 → `move_to_index`
4. **关键参数表**（默认展开，`key_fields_for` 驱动）
5. **全部字段**（默认折叠，`iter_all_fields` + `format_field_value`）
6. 启用勾选 + 备注
7. 按钮：↑ ↓ **复制** 编辑 删除

### 步骤列表重排（Qt + tk `action_chain_page.py`）

- **多选**：Qt `ExtendedSelection` / tk `selectmode="extended"`。
- **批量按钮**：⤒置顶 / ↑上移 / ↓下移 / ⤓置底（支持多选，作用于选中项集合）。
- **拖拽排序**：Qt `_ReorderableTreeWidget`（`dropEvent` 计算 insert 语义 new_order，emit `reordered` 信号）；tk `<ButtonPress-1>/<B1-Motion>/<ButtonRelease-1>`（移动超阈值判定拖拽，释放时计算目标行）。两端均调 `reorder_steps`，由 `CHAIN_STEPS_CHANGED` 事件触发刷新重建。
- 执行中所有写操作被拒，UI 给提示不崩溃。

### i18n

- 新增 `chain.kf.*`（43 个关键字段中文/英文标签）、`chain.detail.*`（key_fields/all_fields/n_items/move_to/move_confirm）、`common.duplicate/move_top/move_bottom`、`chain.msg.invalid_index`（zh/en 同步）。
